# SmartShelf — Windows Local Deployment

> برای نسخه یکپارچه جدید (WebRTC + ارسال JPEG به هوش مصنوعی + کالیبراسیون دو مرجعی) راهنمای `docs/UNIFIED_LOCAL_GITHUB_FA.md` را بخوانید. فرانت‌اند و بک‌اند باید از **یک شاخه/نسخه** باشند؛ نصب انتخابی چند فایل از دو ZIP مختلف پشتیبانی نمی‌شود.

نسخهٔ اصلاحی 1.1 — ۱۲ آبان ۱۴۰۵.

شروع پیشنهادی: فایل `SMARTSHELF-CONTROL.bat` را اجرا کنید. همهٔ مراحل از منوی شماره‌دار در دسترس‌اند.
گزینهٔ ۱ نصب/به‌روزرسانی را انجام می‌دهد. پایان موفق با `INSTALLATION READY` مشخص می‌شود.
PIN مدیر را در محل خصوصی نگه دارید و برای پشتیبانی ارسال نکنید.

برای راه‌اندازی کامل، `docs/WINDOWS_LOCAL_DEPLOY_FA.md` و وضعیت فعلی در `docs/WINDOWS_LOCAL_PROGRESS_FA.md` را بخوانید.

1. استخراج در `C:\SmartShelf`
2. اجرای `INSTALL-SMARTSHELF.bat`
3. ورود به Tailscale
4. اجرای `START-SMARTSHELF.bat`
5. اجرای `ENABLE-FUNNEL.bat` از PowerShell Administrator
6. ثبت Autostart با `scripts\register_autostart.ps1`

پس از ساخت Funnel، بک‌اند را با Ctrl+C متوقف و دوباره اجرا کنید تا آدرس تازه بارگذاری شود.
با `CHECK-SMARTSHELF.bat` یا گزینهٔ ۵ منو، گزارش `logs\diagnostics-latest.json` ساخته می‌شود.
برای ادامهٔ اتصال، فقط همان گزارش یا آدرس عمومی `.ts.net` را ارسال کنید.

اگر قبلاً نصب کرده‌اید: ابتدا از دیتابیس و تصاویر بکاپ بگیرید، اجرای بک‌اند/Task آن را متوقف کنید
و سورس جدید را در پوشهٔ قبلی ادغام کنید. `.env`، `data`، `backups` و `.venv` قبلی را حذف نکنید.
دوباره گزینهٔ ۱ را اجرا کنید تا وابستگی WebSocket نصب شود؛ دیتابیس و کلید معتبر قبلی حفظ می‌شوند.

این بسته شامل سورس SmartShelf، موتور دو مرجعی، مدل ONNX، بک‌اند FastAPI و فرانت‌اند است. هیچ `.env`، PIN، دیتابیس یا گواهی خصوصی داخل ZIP قرار نگرفته است.

در اولین اجرای Production فقط محصول «دلستر هی‌جو هلو» به‌صورت غیرفعال و با قیمت صفر ساخته می‌شود؛ دو جایگاه دیگر خالی هستند. قیمت و فعال‌سازی را فقط پس از تأیید مدیر انجام دهید.
شناسایی هویت محصول در این نسخه عمداً غیرفعال است؛ فقط موتور دو‌مرجعی PRESENT/ABSENT/UNKNOWN برای تشخیص حضور استفاده می‌شود.
