# نقطهٔ ادامهٔ SmartShelf — Windows Local 1.1

تاریخ: ۱۲ آبان ۱۴۰۵ / 2026-11-03

معماری منتخب: FastAPI/OpenCV/SQLite روی Windows فروشگاه، دسترسی HTTPS/WSS با Tailscale Funnel، پنل روی Vercel.

## انجام‌شده در این مرحله

| مورد | نتیجه |
|---|---|
| بررسی بستهٔ قبلی | کامل؛ سورس و ابزارهای Windows حفظ شدند |
| اتصال alias `shelf-ir.vercel.app` | در Vercel تأیید شد؛ پروژه `shelf` |
| وابستگی WebSocket | اضافه شد و با سرور واقعی محلی آزمایش شد |
| فهرست محصول اولیه | قیمت صفر برای پاسخ محصول غیرفعال مجاز شد؛ درخواست فعال‌سازی بدون قیمت معتبر رد می‌شود |
| منوی کنترل | `SMARTSHELF-CONTROL.bat` |
| عیب‌یابی | `CHECK-SMARTSHELF.bat` → `logs/diagnostics-latest.json` |
| تست‌های خودکار | ۱۲۶ مورد موفق روی Linux/Python 3.12 |
| بسته‌های Windows | حل وابستگی‌های باینری برای Windows x64 و CPython 3.14 موفق؛ نصب واقعی انجام نشده |
| سرور واقعی محلی | HTTP، CORS، پاسخ 401 بدون مجوز و WebSocket با بستن اتصال نامعتبر آزمایش شدند |
| دوربین آزمایشی | کد یک‌بارمصرف، توکن دستگاه، ping/pong و فریم JPEG مصنوعی از مسیر واقعی Uvicorn عبور کردند |
| کالیبراسیون | تشخیص PRESENT/ABSENT با تصاویر مصنوعی و حفظ دو مرجع پس از restart سرور موفق بود |
| فروش آزمایشی | ورود مشتری بسته؛ هیچ فاکتور یا قلم سبدی در آزمون فرایند ساخته نشد |

گزارش عیب‌یابی تنها فیلدهای مشخص و نتیجهٔ بررسی‌ها را می‌نویسد؛ فایل `.env`، PIN، کلید، توکن دستگاه، عکس‌ها، حساب Tailscale، فهرست دستگاه‌ها و گزارش خام بک‌اند در آن کپی نمی‌شوند.
آدرس عمومی تونل برای اتصال در گزارش قرار می‌گیرد. وضعیت `store_closed_configured` فقط تنظیم فایل را بیان می‌کند؛ تأیید اعمال آن پس از restart لازم است.

## کاری که روی رایانهٔ فروشگاه لازم است

1. استخراج بسته به‌گونه‌ای که `C:\SmartShelf\SMARTSHELF-CONTROL.bat` مستقیماً وجود داشته باشد؛ پوشهٔ اضافه داخل آن نباشد.
2. اجرای همان فایل و گزینهٔ ۱. پس از `INSTALLATION READY`، PIN تازه را خصوصی ذخیره کنید.
3. گزینهٔ ۲: نصب Tailscale از سایت رسمی و ورود به حساب خودتان.
4. گزینهٔ ۳: راه‌اندازی بک‌اند و باز نگه‌داشتن پنجرهٔ آن.
5. گزینهٔ ۴: ساخت Funnel و انجام ورود/مجوزی که خود Tailscale نشان می‌دهد. ایجاد Funnel سرویس احراز هویت‌شده را در اینترنت عمومی قابل دسترس می‌کند.
6. توقف بک‌اند با Ctrl+C و اجرای دوبارهٔ گزینهٔ ۳؛ سپس گزینهٔ ۵ برای گزارش.
7. ارسال فقط آدرس `https://…ts.net` یا `logs/diagnostics-latest.json` برای ادامه. در صورت شکست نصب، متن خطا را بدون PIN ارسال کنید.

## مرحلهٔ پس از دریافت آدرس

- بررسی HTTPS، WSS، مجوزها و CORS از بیرون شبکهٔ فروشگاه.
- آماده‌سازی و آزمون رابط یکپارچه در Vercel Preview با مبدأ مجاز دقیق همان Preview.
- جفت‌سازی تبلت، اجازهٔ دوربین و تست ارسال پایدار فریم در نور و زاویهٔ واقعی.
- ثبت دو مرجع و ROIهای واقعی؛ آزمون برداشت/بازگرداندن بدون فروش واقعی.
- آزمون اجرای خودکار بعد از ورود Windows و ماندگاری دیتابیس و تصاویر.

این مرحلهٔ کار، انتشار جدید Vercel، نصب روی Windows، فعال‌سازی واقعی Funnel یا آزمایش فیزیکی قفسه را انجام نداده است.
فروشگاه تا پایان اعتبارسنجی بسته می‌ماند. تشخیص هویت با مدل عمومی همچنان غیرفعال است.
